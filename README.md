# Bank Management System (C++)
A console-based Bank Management System built using C++.
The project allows users to manage bank clients, perform transactions, and store data permanently using text files.

This project was built to practice:- File Handling
- Data Validation
- Clean Code

## Features
- View all clients
- Add new client
- Update client information
- Delete client
- Search by account number
- Deposit money
- Withdraw money
- Display all balances
- Calculate total bank balance
- Persistent data storage using text files

## Technologies
- C++
- Standard Template Library (STL)
- File Handling
- Vectors
- Structs & Enums
- Console Application
